# Vue前端设计

沿用用户确认的下一阶段：将聊天、知识库上传和行程展示接成可演示应用。采用Vue3＋Vite单页工作台，中文界面、青绿色与米白配色、桌面侧栏及窄屏顶部导航。不增加大型组件库、登录系统或新的后端业务。

智能客服：POST fetch解析SSE，支持跨字节UTF8和跨网络块事件，处理meta/delta/done/error；显示生成／取消／失败状态、候选资料引用；退款仅由done返回的确认令牌驱动，点击前二次确认，明确演示操作。中断不将半截答案视为已保存成功。

行程助手：自然语言需求框，POST plan，GET当前会话保存状态；展示缺需求追问、缺资料、超预算、每日景点／天气／室内备选／费用与演示标识。刷新恢复会话标识与服务端状态；失败保留旧行程；409提示重新读取，不自动覆盖。

知识库：选择PDF、Word、Markdown、文本文件，multipart上传，显示实际导入数量与结果；关键词检索展示资料标题和内容。普通文件上传不等于结构化行程景点导入，使用中文说明区分。

会话：仅本机localStorage保存随机conversationId及导航页，不保存Key或完整回答。新会话切换标识，保留服务端旧数据。切换会话前取消聊天请求；行程生成期间禁用新会话操作，避免请求结果错绑。组件卸载取消流和读取请求。

访问：Vite绑定127.0.0.1:5173，/api代理到127.0.0.1:8080（允许Vite配置的服务端环境变量修改）。预览代理相同，仅为本机演示；生产部署需同源反向代理。所有模型输出通过Vue文本插值展示，禁止v-html，避免上传资料和回答成为执行脚本。

验证：node:test覆盖HTTP错误、SSE跨块／多行／CRLF／空delta／取消／缺done；Playwright浏览器测试覆盖聊天引用、确认令牌、行程生成修改和恢复、上传检索、窄屏无横向溢出。真实后端联调至少验证一次完整流式问答，生产构建通过；付费调用保持少量。
