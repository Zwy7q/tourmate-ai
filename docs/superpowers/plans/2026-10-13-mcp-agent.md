# MCP 工具与 Agent 实施计划

目标：实现真实 MCP 工具发现、调用和 ReAct 工具循环，保留原有 RAG 与人工确认。

架构：新增 tools-server，backend 新增 MCP 配置与 AgentAnswerGenerator，共用上下文提示词。MCP 内仅有只读能力。

## 工具服务

- [x] 创建 tools-server/pom.xml，统一 Spring Boot、Spring AI 版本，使用 MCP server WebMVC starter。
- [x] 先写 WeatherToolsTest，本机 HTTP 提供天气 JSON，验证固定城市坐标、日期、来源、失败及日期限制；再实现 WeatherTools。城市采用固定白名单，没有地理编码接口。
- [x] 提供 get_demo_order，只接受固定的演示编号并标注 demo=true；未知编号无订单数据。
- [x] 注册 ToolCallbackProvider，编写协议测试通过 SDK initialize、listTools、callTool 验证工具发现与执行。
- [x] 在 tools-server 执行 `mvn -s ../backend/maven-central-settings.xml clean verify`。

## 后端 Agent

- [x] 引入匹配 Spring AI 版本的 Alibaba Agent Framework，MCP client SDK。
- [x] 提取 GenerationPrompt，分别为旧模式和 Agent 模式保留正确的天气说明。
- [x] 新增 agent profile，MCP 标准 HTTP 客户端只注册 get_weather 和 get_demo_order，封装调用次数与失败结果。
- [x] 新增 AlibabaAgentAnswerGenerator，每请求独立 Agent；按模型轮次缓冲后过滤调用工具的中间输出，不保证首 Token 实时展示。
- [x] 用本机模型服务器验证非工具请求与 Agent 模型—工具—模型循环；补回归测试覆盖先输出文本再调用工具。
- [x] 保留退款令牌流程，Agent 模式天气不提前调用演示工具。
- [x] 全量运行 backend clean verify 与显式数据库集成测试。
